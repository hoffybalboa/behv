BEHV

A personal automation agent that its owner runs on their own computer for their own Google account. It reads the owner's mail, calendar and Drive so that it can draft replies, file documents and keep a task list current. It is not a product, it has no other users, and nothing about it is offered to anyone else.

This page exists because Google requires a published home page for any application that uses its sign-in, including one whose only user is its author.
